# Writeup — Вентилятор303 (SolarCTF 2026)

**Категория:** misc / audio
**Дата:** 2026-10-17
**Цель:** `ventilator303.wav` (WAV, 16-bit PCM, 44100 Hz, моно)
**Флаг:** `SOLARCTF{YuG0sl4v1a-Galaks1ja-DIY-Z1L0G80Z}`

## Условие

Дан аудиофайл, в котором, согласно описанию, записана передача программы с кассеты времен балканского радио. Задача — извлечь из него скрытый флаг.

## Разведка

1. **Анализ описания.** Подсказка отсылает к передаче «Вентилятор 202» на Радио Белград (1980-е), в эфире которой транслировали аудиозаписи программ для 8-битных компьютеров (ZX Spectrum, Galaksija, C64).
2. **Осмотр WAV.** В файле: `file` выдает PCM 16-bit моно 44100 Hz, длительность 168 секунд. Первые 3 секунды — громкий сигнал, затем тишина, после чего идут основные данные.
3. **Анализ частот.** Строим гистограмму длительностей полупериодов (расстояний между переходами через ноль с гистерезисом, чтобы отсечь шум). Обнаруживаются два четких пика: ~9-10 сэмплов и ~18-19 сэмплов. Это указывает на два символа (0 и 1), то есть частотную модуляцию (FSK).

## Уязвимость

1. **Неверная гипотеза (ловушка).** Сначала кажется, что это стандартная запись ZX Spectrum (пилот-тон, короткий период = 0, длинный = 1). Но тайминги не сходятся, а в декодированных байтах виден повторяющийся паттерн `24 92 49` (биты `100100`), что говорит об ошибке.
2. **Определение модуляции.** При детальном рассмотрении волны выясняется, что она гладкая (синусоида), а не прямоугольная. Паттерн повторяется: один длинный период (36 сэмплов = 1200 Гц), затем два коротких (18 сэмплов = 2400 Гц). Это стандарт записи **Kansas City Standard (KCS) 1200 бод** (бит 0 = 1200 Гц, бит 1 = 2400 Гц). Наш "сбойный" паттерн оказался преамбулой `0x55`.
3. **Плывущая нулевая линия.** Декодирование по переходам через ноль дает ошибки, так как длительности полупериодов становятся несимметричными. Для надежности нужно сравнивать энергию сигнала на двух частотах.

## Эксплуатация

1. **Демодуляция FSK.** Умножаем сигнал на комплексную экспоненту для 1200 Гц и 2400 Гц, считаем разницу энергий `D = |2400| - |1200|`. Если `D > 0` — это бит 1, иначе 0. Применяем UART-кадрирование (старт-бит, 8 бит данных, стоп-бит). Каждый старт-бит синхронизирует часы заново.
2. **Проверка контрольной суммой.** После демодуляции получаем заголовок `VENTILATOR-303 TAPE v1 / NAME: GALAKSIJA-DEMO`. Чтобы убедиться в корректности, проверяем XOR блоков TAP (должен быть 0) и CRC-CCITT заголовка (совпадает с `CSUM: 88D9`).
3. **Разбор TAP-файла.** Внутри 4 блока: два заголовка и два блока с данными. Из заголовков узнаем, что это программа на BASIC, которая загружает машинный код (Z80) по адресу `0x8000`.
4. **Эмуляция кода.** В коде Z80 лежит таблица перестановок и шифртекст. Вместо ручного реверса проще запустить эмулятор Z80. Подаем код по адресу `0x8000` и перехватываем вызовы процедуры печати символа (по адресу `0x80A7`). Программа медленно выводит символы с задержками, собирая флаг на экране.

## Воспроизведение

Для работы потребуются `numpy`, `scipy`, а также эмулятор Z80 (например, `kosarev/z80` для Python).

**Демодуляция FSK + UART:**
```python
import numpy as np
import scipy.io.wavfile as w

sr, x = w.read('v.wav')
x = x.astype(float)
T = sr / 1200  # Длительность одного бита (36.75 сэмпла)

n = np.arange(len(x))
def env(f):
    c = x * np.exp(-2j * np.pi * f * n / sr)
    return np.abs(np.convolve(c, np.ones(int(round(T))) / T, 'same'))

D = env(2400) - env(1200)
res = bytearray()

for p in range(len(D) - int(T*10)):
    if D[p] < 0 <= D[p-1]:                 # фронт старт-бита
        c = p + T / 2                      # центр старт-бита
        bits = [D[int(c + T*(k+1))] > 0 for k in range(9)]
        if bits[8]:                        # проверка стоп-бита
            res.append(sum(b << j for j, b in enumerate(bits[:8])))
```

**Запуск в эмуляторе:**
1. Инициализируем память 64 КБ, код кладем по адресу `0x8000`. Вместо ROM заполняем память инструкцией `RET` (`0xC9`), чтобы вызовы системных функций Spectrum просто возвращали управление.
2. Устанавливаем `PC = 0x8000`, `SP = 0xFF00`.
3. Запускаем цикл эмуляции и перехватываем вызовы подпрограммы по адресу `0x80A7` (вход: `A` — символ, `B` — строка, `C` — столбец).
4. Ждем, пока счетчик по адресу `0x83C2` не дойдет до 43. Склеиваем две строки на экране в единый флаг.

## Вывод

Таск проверяет навыки работы с сигналами и эмуляторами старых платформ. Главный урок: не стоит доверять первой гипотезе (ZX Spectrum), нужно смотреть на реальную форму сигнала. Использование энергии частот (вместо переходов через ноль) и проверка контрольными суммами (CRC) позволили получить точные данные. Запуск кода в эмуляторе с перехватом вывода оказался быстрее и надежнее, чем ручной дизассемблинг Z80.
