## TL;DR

RSA, но не над целыми числами, а над многочленами из $GF(257)[x]$. Вся защитная магия RSA держится на том, что $\varphi(N)$ нельзя посчитать, не факторизовав $N$. Здесь же $\varphi$ зависит только от **степеней** двух неприводимых множителей, а степени (58 и 59) лежат прямо в публичном исходнике. Дальше три шага: $\varphi \to d \to m = c^d \bmod N$, и коэффициенты $m$ — это флаг.

## 1. Что дано

`chall.sage` — полный листинг генератора:

```python
#!/usr/bin/env sage
#
# Textbook RSA... but over polynomials instead of integers.
#
# We work in the ring R = GF(257)[x]. The modulus is a product of two
# "primes" (irreducible polynomials) N = P * Q, the public exponent is e,
# and a message polynomial m is encrypted as c = m^e mod N.
#
# The flag is encoded as the coefficients of m (constant term first).

p = 257
R.<x> = GF(p)[]
e = 65537

with open('flag.txt', 'rb') as f:
    flag = f.read().strip()

# message polynomial: flag bytes become coefficients m_0 + m_1*x + m_2*x^2 + ...
m = R([GF(p)(b) for b in flag])

while True:
    # two random irreducible polynomials -- the "primes" of our RSA
    P = R.irreducible_element(58, algorithm='random')
    Q = R.irreducible_element(59, algorithm='random')
    N = P * Q

    # number of units of R/(N), i.e. the analogue of Euler's phi for RSA
    phi = (p**P.degree() - 1) * (p**Q.degree() - 1)
    if gcd(e, phi) == 1:
        break

c = power_mod(m, e, N)

with open('output.txt', 'w') as f:
    f.write(f'p = {p}\n')
    f.write(f'e = {e}\n')
    f.write(f'N = {N.list()}\n')
    f.write(f'c = {c.list()}\n')
```

## 2. Классический RSA: пять минут теории

### 2.1 Схема

1. Берём два больших простых $p, q$, модуль $N = pq$.
2. $\varphi(N) = (p-1)(q-1)$ — функция Эйлера: сколько чисел от 1 до $N$ взаимно просты с $N$.
3. Публичная экспонента $e$: взаимно проста с $\varphi(N)$.
4. Приватная экспонента $d = e^{-1} \bmod \varphi(N)$ — число с свойством $ed \equiv 1 \pmod{\varphi(N)}$.
5. Шифрование: $c = m^e \bmod N$. Расшифрование: $m = c^d \bmod N$.

### 2.2 Почему расшифровка возвращает $m$

Множество обратимых вычетов $(\mathbb{Z}/N\mathbb{Z})^{\times}$ — конечная мультипликативная группа порядка ровно $\varphi(N)$. По теореме Лагранжа порядок любого элемента делит порядок группы, поэтому для всякого $a$ с $\gcd(a, N) = 1$:

$$a^{\varphi(N)} \equiv 1 \pmod{N}.$$

Из $ed = 1 + k\varphi(N)$ следует (для $m$, взаимно простого с $N$):

$$m^{ed} = m^{1 + k\varphi(N)} = m \cdot \left(m^{\varphi(N)}\right)^k \equiv m \cdot 1^k = m \pmod{N}.$$

То есть возведение в $e$, а потом в $d$ — это «кругосветное путешествие» по группе, которое возвращает тебя домой.

### 2.3 Почему RSA сложно сломать

Чтобы получить $d$, нужно $\varphi(N)$. А $\varphi(N)$ вычислить без $p$ и $q$ нельзя — и это равносильные сложности: если $\varphi$ известна, то

$$\varphi = (p-1)(q-1) = N - (p + q) + 1 \;\Rightarrow\; p + q = N + 1 - \varphi,$$

и $p, q$ — корни квадратного уравнения $x^2 - (p+q)x + N = 0$. Знание $\varphi \Leftrightarrow$ факторизация $N$. На этом равенстве сложностей стоит вся классика.

## 3. Мир многочленов: $GF(257)[x]$

### 3.1 Конечное поле $GF(p)$

$GF(p)$ — числа $\{0, 1, \dots, p-1\}$ со сложением и умножением по модулю $p$. Если $p$ простое, это **поле**: у каждого ненулевого элемента есть обратный, деление работает. $257$ — простое (проверяется делением на 2, 3, 5, 7, 11, 13), и это не случайный выбор: байт принимает значения $0 \dots 255$, значит $257$ — минимальное простое, в которое байт «влезает» целиком. Каждый коэффициент многочлена — ровно один байт флага.

### 3.2 Кольцо многочленов

$GF(p)[x]$ — многочлены с коэффициентами в $GF(p)$. Складываются и умножаются как в школе, только каждый коэффициент результата приводится по модулю 257. Кольцо факториально и евклидово: есть деление с остатком, есть НОД — весь «инструментарий целых чисел» переносится.

### 3.3 Неприводимые многочлены = простые числа

Многочлен неприводим, если не раскладывается в произведение многочленов меньшей степени. Это точный аналог простого числа. Пример того, что «простота» зависит от поля: $x^2 + 1$ над $GF(3)$ принимает значения $1, 2, 2$ — корней нет, значит неприводим (для степени $\le 3$ отсутствия корней достаточно); а над $GF(2)$ он равен $(x+1)^2$ — приводим.

Ключевой факт (аналог $\mathbb{Z}/p$ — поле): фактор-кольцо $GF(p)[x]/(P)$ является полем **тогда и только тогда**, когда $P$ неприводим. Если $\deg P = d$, остатки от деления на $P$ — это многочлены степени $< d$, то есть $d$ коэффициентов по $p$ вариантам: ровно $p^d$ элементов. Такое поле обозначается $GF(p^d)$.

## 4. Вывод формулы $\varphi$ (то, что в исходнике назвали «аналогом фи Эйлера»)

### 4.1 CRT — китайская теорема об остатках

$P$ и $Q$ — различные неприводимые, значит взаимно простые. CRT для колец даёт изоморфизм:

$$GF(p)[x]/(N) = GF(p)[x]/(PQ) \;\cong\; GF(p)[x]/(P) \times GF(p)[x]/(Q) \;\cong\; GF(p^{58}) \times GF(p^{59}).$$

Работать с «большим кольцом по модулю $N$» — то же самое, что работать с парой независимых полей.

### 4.2 Порядок группы единиц

Обратимый элемент произведения — это пара обратимых: $(a, b)$ обратима $\Leftrightarrow$ $a$ обратим в первом кольце И $b$ во втором. В поле обратимо всё, кроме нуля, поэтому:

$$\left|\left(GF(p)[x]/(N)\right)^{\times}\right| = (p^{58} - 1)(p^{59} - 1).$$

Это и есть $\varphi$, которую считает цикл в `chall.sage`. Обрати внимание: **в формуле нет ни P, ни Q — только их степени.**

### 4.3 Тонкость: сообщение-неединица

Флаг короткий, его многочлен может целиком попасть в «младшие степени» и даже делиться на $P$ — тогда $m$ не единица, и рассуждение из п. 2.2 к нему напрямую не применимо. Но расшифровка всё равно точна: в поле $GF(p^d)$ рассмотрим отображение $x \mapsto x^{ed}$, где $ed = 1 + k(p^d - 1)$:

- для $x \ne 0$: $x^{ed} = x \cdot (x^{p^d-1})^k = x$;
- для $x = 0$: $0^{ed} = 0$.

Значит $x^{ed} = x$ для **всех** элементов каждого поля, и по CRT $m^{ed} \equiv m \pmod{N}$ для любого $m$ — включая неединицы.

### 4.4 Зачем автору цикл с `gcd(e, phi) == 1`

Ровно из п. 2.1: $d = e^{-1} \bmod \varphi$ существует только при $\gcd(e, \varphi) = 1$. Если бы НОД был больше 1, отображение $x \mapsto x^e$ на группе единиц перестало бы быть биекцией — по $c$ восстановить $m$ было бы нельзя (информация теряется).

## 5. Уязвимость

В целочисленном RSA $\varphi = (p-1)(q-1)$ требует **самих** $p$ и $q$, и их поиск — нерешённая задача. Здесь $\varphi$ требует только **степеней** множителей, а степени:

1. явно написаны в публичном исходнике: `irreducible_element(58)` и `irreducible_element(59)`;
2. подтверждаются данными: $\deg N = 117 = 58 + 59$ (я просто посчитал коэффициенты в `output.txt`).

То есть аналог факторизации автор сделал за нас, приложив исходник. Бонус: даже без исходника схема не выдержала бы — факторизация многочленов над конечным полем полиномиальна (алгоритм Кантора–Цассенхауза), в Sage это `R(N).factor()` за секунды. «Сложность» этой RSA — фикция дважды.

## 6. Эксплуатация

Sage поднять не удалось, и он не понадобился: всё решается чистым Python + библиотекой `galois` (`pip install galois`) — она умеет арифметику многочленов над $GF(p)$, включая трёхаргументный `pow(base, exp, mod)` (возведение в степень с приведением по модулю; эквивалент square-and-multiply с редукцией на каждом шаге).

Мой финальный скрипт:

```python
# solve.py — чистый Python + galois
import galois

# данные из output.txt — строки p, e, N, c копируются как есть (это валидный Python)
p = 257
e = 65537
N = [...]   # 118 коэффициентов из output.txt
c = [...]   # 117 коэффициентов из output.txt

# 1) аналог phi: степени 58 и 59 взяты из публичного исходника
phi = (p**58 - 1) * (p**59 - 1)

# 2) приватная экспонента
d = pow(e, -1, phi)
print(d.bit_length())   # 937 — чекпоинт: phi ~ 257^117 ~ 2^936.7

# 3) многочлены. Ловушка №1: в output.txt константа идёт ПЕРВОЙ,
#    а galois ждёт список от старшей степени к младшей
GF = galois.GF(257)
N_poly = galois.Poly(GF(list(reversed(N))))
c_poly = galois.Poly(GF(list(reversed(c))))

# 4) расшифровка: m = c^d mod N
m_poly = pow(c_poly, d, N_poly)
print(m_poly.degree)    # 39 → флаг длиной 40 символов

# 5) коэффициенты → байты → строка. Ловушка №2: переворачиваем обратно,
#    чтобы вернуть порядок "constant term first"
coeffs = [int(x) for x in m_poly.coeffs]
flag = bytes(list(reversed(coeffs)))
print(flag.decode())
```

Контрольные точки, которые я проверял по ходу (и которые поймали бы ошибку раньше, чем я стал бы разбирать мусорный вывод):

- `d.bit_length()` = **937** — совпало с оценкой $\log_2 \varphi \approx 117 \cdot \log_2 257 \approx 936.7$;
- `m_poly.degree` = **39** → флаг из 40 байт: `ctfcup{` (7) + 32 hex-символа + `}` = 40 ✓.

## 7. Что я вынес

1. **Читать исходник до конца и медленно.** Числа 58 и 59 висели в коде открытым текстом — вся задача «взорвалась» именно из-за них.
2. **RSA — это не про числа, а про группы.** Где есть конечная группа известного порядка и $e$, взаимно простое с ним, — там работает схема «$c = m^e$, $m = c^d$». Числа, многочлены, эллиптические кривые — вопрос носителя.
3. **Стойкость переносится не всегда.** «Факторизация сложна» — правда для целых чисел и ложь для многочленов над конечными полями.
4. **Чекпоинты экономят часы.** Ожидаемые размеры (937 бит, степень 39) стоило посчитать до запуска — они мгновенно отделяют «работает» от «мусор».
5. **Отсутствие инструмента — не стоп.** Нет Sage — есть чистый Python и `galois`.
