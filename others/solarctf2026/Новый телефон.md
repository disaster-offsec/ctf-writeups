# Новый телефон

**Флаг: `SOLARCTF{y_MTC_n0v0e_1its0_yayts0}`**

## Кратко

Требовалось определить точку съёмки по скриншоту камеры. Визуальный поиск и панорамы привели к Кольцевой улице в микрорайоне Новый Таёжный в Тынде. Успешные координаты найдены ограниченным локальным перебором через предоставленный пользователем endpoint проверки.

## Решение

### 1. Найти участок

В исходном скриншоте (new_phone.jpg) отсутствует EXIF. По фрагменту дома обратный поиск Яндекса дал фотографии недвижимости Тынды. Наземные панорамы Кольцевой подтвердили вышку, красные торцы домов, светлые фасады и бетонный спуск. Пользователь подтвердил участок и предложил визуальную опору 55.162336,124.772865.

Перспективная модель не дала достоверной точности: предложенная ею точка не принята. После получения endpoint использован прямой серверный критерий, без дальнейшей подгонки изображения.

### 2. Проверить координаты и получить флаг

Пользователь разрешил отправлять координаты на /submit. Неподходящие точки возвращали `{"not":"aaa"}`, успешная — поле `received`. Сетка с шагом 8 м проверялась последовательно вокруг опоры; при успехе поиск остановлен.

Принята точка **55.162336,124.7721101870**. Она является проверенным сервером допустимым ответом; это не утверждение, что координата совпадает с физической камерой до сантиметра.

Воспроизведение (Python 3.12, requests):

```python
import requests

r = requests.post(
    'https://new-phone.solarctf.ru/submit',
    json={'lat': '55.1623360000', 'lon': '124.7721101870'},
    timeout=25,
)
r.raise_for_status()
print(r.json()['received'])
```

Успешный ответ сервера (HTTP 200, 2026-10-17T16:59:37Z):

```json
{"received": "SOLARCTF{y_MTC_n0v0e_1its0_yayts0}"}
```

История перебора: журнал содержит 113 отправок координат; успешной оказалась последняя. Более ранняя модельная оценка сервером не принималась.
