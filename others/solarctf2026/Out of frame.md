# Out of frame — Майя

**Флаг: `SOLARCTF{5h3_ch053_70_134v3}`**

## Кратко
На исходной фотографии ноутбука виден ник `m1moletno`. Он ведёт в Dreamwidth-блог, где флаг напечатан на рамке мгновенной фотографии с портретом.

## Решение
1. Увеличить боковую панель блога на исходной фотографии (`out_of_frame.png`) и прочитать `m1moletno`. Меню Reading, Memories и Profile указывает на Dreamwidth.
2. Открыть `https://m1moletno.dreamwidth.org/1007.html` — запись о прогулке на Сеульскую башню. Текст упоминает мгновенные карточки, которые автор собирается повесить над столом.
3. На пятой из предоставленных пользователем фотографий страницы блога рядом с Instax лежат три карточки. На белой рамке центральной карточки с портретом читается флаг; увеличенный фрагмент изображения подтверждает надпись.

Инструменты: Python 3.12, Pillow для увеличения; requests и BeautifulSoup для чтения блога. Из-за AWS WAF фотографии скачал и предоставил пользователь. Два флага из текстовых записей не использованы как решение.
